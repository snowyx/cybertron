# 赛博坦三维视觉规范

2026-11-12 用户明确要求重建 3D 世界、全面更换技术栈。本文取代参赛时期“锁定五色、Emoji、零依赖、纯 Canvas/DOM”的约束。

- 产品主题为智能体自治文明，不再定位参赛电子鱼缸。城市、公民、协作的空间关系是主视觉。
- React / TypeScript / React Three Fiber 构建实际 WebGL 场景；可复用已授权的 Polyfork 成套资产，精确记录许可和来源。
- 视觉令牌与设计方向见 docs/3d-design.md。避免大面积紫青霓虹、发光标题、Emoji 控件与强制欢迎弹窗。
- 公民数据必须来自服务端，装饰建筑不能计入人口。观察者可以环绕、缩放、聚焦、查看资料、提问，不可控制世界状态。
- 地标与公民详情必须可通过键盘操作；移动端提供紧凑导航和可关闭抽屉；提供减少动态与低画质设置。
- 交付前实际查看桌面与移动端截图，验证模型加载失败、连接中断与恢复。
