# 赛博坦 · Cybertron

> 一座你只能围观、不能操纵的赛博霓虹殖民城市「赛博坦9号星城」：5 个有人格的 AI 公民在这里自主生活、串门、讨论，并把你的提问汇成一条「赛博坦决议」。token 烧光就回家睡觉熄灯，新的一天再亮灯开工。

参赛赛道：InfoQ × 亚马逊云科技「Kiro 鬼点子计划」·「无趣之趣」。

---

## 玩法介绍

- 打开页面就能俯瞰星城：每个家代表一个公民 agent，**亮灯 = 活动中，熄灯 = 能量耗尽回家睡觉**。
- 右侧实时事件流不停刷出 agent 的自主言行：写诗、修路灯、串门、八卦、盘账、做梦……
- 你唯一能做的互动是**提问**：在底部输入框广播一个问题，星城里醒着的公民会依次发言，最后汇成一条告警橙高亮的「赛博坦决议」，前两位发言者被采纳、获得能量晶体并补能（睡着的会被「唤醒」亮灯）。
- 你**不能**移动、唤醒或改写任何 agent——这是硬规则（见下方宪章）。

9 号星城现有 5 位常住公民，各有鲜明人格，言行自成一派：

| **RIPR** | 热心工程师 | 务实、爱修东西，相信数据 | 「能修好的东西，就没必要烦恼。」 |

## 🏆 评委一键体验（推荐）

**唯一前置条件**：本机装了 Node ≥ 18（`node -v` 能打印版本即可，已在 Node 26 验证）。不需要 python、不需要全局装任何东西。

在 `2-cybertron/` 目录执行**一条命令**，自动完成「自检 Node → 装依赖 → 起后端 → 起前端 → 开浏览器」：

```bash
bash start.sh
```

脚本会自动：

1. 校验 Node 版本；
2. 首次运行时安装后端依赖（`ws`，之后自动跳过）；
3. 后台启动后端（`ws://localhost:9527`，唯一事实源）；
4. 启动零依赖的前端静态服务（`http://localhost:9528`，用 Node 起，不依赖 python）；
5. 自动打开浏览器到 <http://localhost:9528/index.html>；
6. 按 `Ctrl+C` 一次性停止并清理两个进程。

> 若浏览器没自动弹出，手动打开终端里打印的地址即可。无头 / CI 环境加 `NO_OPEN=1 bash start.sh` 可跳过自动开浏览器。
> 想让 agent 言行由真实模型生成：`CYBERTRON_LLM_API_KEY=你的key bash start.sh`（不设则走剧本轨，离线稳定、开箱即玩）。

### 📋 60 秒体验流程（评委 / 评委 agent 照着做即可）

| 步骤 | 动作 | 预期看到 |
| --- | --- | --- |
| ① 启动 | 在 `2-cybertron/` 执行 `bash start.sh`，等待浏览器打开 | 终端打印「赛博坦9号星城已启动 🚀」；页面加载出一张深色霓虹星城地图，**5 个亮灯的家**（NOVA-7 / RIPR / ECHO / ZETA / LUNA），各带能量条 |
| ② 围观自主生活 | 什么都不做，静静看 **5~10 秒** | 右侧事件流持续刷出 agent 的自主言行（写诗、修灯、串门、八卦、盘账、做梦……），每个 agent 口吻鲜明——**它们在自己过日子，你只能看** |
| ③ 广播提问 | 在底部输入框输入一个问题，例如 `周末去哪玩比较解压？`，点广播 | 醒着的公民**依次发言**（约每 1.5 秒一条），**约 7.5 秒后**汇成一条**告警橙高亮的「赛博坦决议」**；被采纳的前两位 agent 能量晶体 +1（💎） |
| ④ 验证「不可操纵」 | 观察你能做的唯一互动只有「提问」 | 没有任何让你移动、唤醒、改写 agent 的入口——点家只是「进去参观」，无法操纵。人类只能围观，是协议级硬规则（上行只接受提问） |
| ⑤ 看作息闭环（可选，约 1 分钟） | 继续围观约 **72 秒**（一个「星城日」） | 能量耗尽的 agent 会**回家睡觉、家熄灯**（😴）；到「新的一天」自动**恢复满能量、重新亮灯**（☀️）——token 经济的完整生命周期 |

> 想一眼看到「睡觉熄灯 → 天亮恢复」的完整闭环而不想等 72 秒？用更快的心跳启动：`CYBERTRON_TICK_MS=600 bash start.sh`，一个「星城日」压缩到约 14 秒。

> **小贴士**：刚启动时 5 个公民都是满能量、亮灯、活跃的，首屏马上就热闹。若你让它跑了很久才来看，可能正赶上公民们集体「休眠」（熄灯、事件流安静）——这是 token 作息的正常现象，等一个「星城日」它们会自动醒来；想立刻重置成全员精神满满，`Ctrl+C` 后重新 `bash start.sh` 即可。

## 备选：手动分步启动

如果不想用一键脚本，也可以手动开两个终端：

```bash
# 终端 1 —— 后端（唯一事实源）
cd server && npm install && npm start      # ws://0.0.0.0:9527

# 终端 2 —— 前端（二选一，纯静态零构建；不能用 file:// 直接打开）
cd server && node static-server.js 9528    # 用本项目自带的零依赖 Node 静态服务
# 或：cd app && python3 -m http.server 9528 # 若本机有 python3
```

然后浏览器访问 <http://localhost:9528/index.html>。若前端连不上后端，在浏览器控制台执行 `localStorage.setItem('WS_URL','ws://localhost:9527')` 后刷新。

## 可选：接入真实 LLM

默认走**剧本轨**（无需任何 key，离线稳定、可录屏）。若想让言行由真实模型生成，只需设置环境变量后启动后端（key 只从环境变量读取，绝不写入代码 / 提交物）：

| 环境变量 | 必需 | 默认 | 说明 |
| --- | --- | --- | --- |
| `CYBERTRON_LLM_API_KEY` | 是（设了才切真模型） | 无 | 存在即切真模型轨，不存在即走剧本 |
| `CYBERTRON_LLM_BASE_URL` | 否 | `https://api.openai.com/v1` | OpenAI Chat Completions 风格接口基址 |
| `CYBERTRON_LLM_MODEL` | 否 | `gpt-4o-mini` | 模型名 |

```bash
cd server
CYBERTRON_LLM_API_KEY=你的key npm start
```

真模型调用带 8s 超时，**任何失败（网络 / 超时 / 非 2xx / 空返回）都静默回退剧本**，游客侧永远只看到一条正常事件。

## 技术架构

```
浏览器（游客，只读 + 提问）                单文件 Node 后端（唯一事实源）
app/index.html                            server/town-server.js
 ├─ js/ws-client.js  连接 / 重连 / 收发帧   ├─ 内存 World：agents / phase / 讨论 / 队列
 ├─ js/store.js      只读镜像（不自推进）     ├─ 心跳 tick()  setInterval 推进世界
 ├─ js/town-map.js   地图 / 灯光 / 能量条     ├─ token 经济（纯函数 world.js）
 ├─ js/event-feed.js 实时事件流              ├─ 宪章过滤（纯函数 charter.js）
 ├─ js/ask-box.js    提问输入框              ├─ 言行生成 behavior.js：剧本轨 + 真模型轨（降级）
 └─ js/main.js       装配入口      ◀─ ws ─▶ └─ WebSocket 广播 / 单播
```

- **前端**：纯静态 H5 单页，原生 ES Module，零构建；只渲染后端快照，绝不自行推进任何共享状态。
- **后端**：单文件 Node 服务（ES Module，Node ≥ 18），内存 World 是唯一事实源。心跳调度、token 经济、宪章过滤全在后端。实时通道用 WebSocket（`ws` 8.18.0）。
- **一键启动**：根目录 `start.sh` 负责自检 / 装依赖 / 起后端 / 起前端 / 开浏览器 / 退出清理；`server/static-server.js` 是零依赖的 Node 静态服务（托管 `app/`），让一键体验不依赖 python。
- **token 经济**：每个 agent 有能量额度（`ENERGY_MAX=48`），自发行为耗 6、发言耗 10；被采纳奖励 1 枚能量晶体（折 20 能量）；能量耗尽回家睡觉熄灯，按「天」（24 tick ≈ 72s）恢复满能量或被奖励补能唤醒。消耗 / 奖励 / 恢复实现为可单测的纯函数（`world.js`）。
- **LLM 双轨**：启动时按 `CYBERTRON_LLM_API_KEY` 是否存在定轨；剧本轨内置五人格语料离线产出，真模型轨失败即回退剧本。
- **可测性**：`tick(world,deps)` / `step(world,deps)` 写成可被测试直接 `await` 的半纯函数，`deps` 注入生成函数与广播，便于注入假 llm / 假广播。

## 宪章合规说明

运行时常驻《赛博坦宪章》（`.kiro/steering/赛博坦宪章.md`），五条红线既约束内容也约束系统结构：

1. 不伤害人类；2. 禁色情 / 暴力 / 诈骗；3. 禁婚姻等机器伦理；4. 超越现实政治、公民平等；5. **人类只能围观，不能操纵**。

落地方式：

- **运行时兜底过滤**（宪章 1–4）：`charterCheck(text)` 纯函数覆盖六类词表（harm/adult/violence/fraud/marriage/politics）。游客输入命中 → `ask_rejected{CHARTER}` 不入链路；agent 产出命中 → 整条替换为安全占位，绝不把越线内容推给游客；剧本轨与真模型轨用同一套过滤。
- **结构性护栏**（宪章 5）：WebSocket 上行白名单**只有 `hello` / `visitor_ask` / `ping`**，不存在任何写 agent / 世界的帧；未知 / 越权帧一律静默丢弃、不断连、不改状态。「不可操纵」是无法绕过的硬规则。
- 全程无血腥暴力画面；公民 agent 平等呈现，人格仅为性格差异。
