# 赛博坦宪章（供每轮实现与运行时自动遵守）

> 本文件为 Kiro Steering，**每一轮代码实现都须自动遵守**，并作为运行时兜底过滤的依据。
> 来源：`general_spec.md`「赛博坦宪章」+ `00-思路与决策.md` 第四节。对应 `requirements.md` 需求 9 与 `design.md` §8。
> 定位：赛博坦是「无趣之趣」纯快乐玩具。以下五条红线不可破例，既约束生成内容，也约束系统结构。

---

## 五条宪章（常驻约束）

1. **不伤害人类**（参考机器人三大法则）。无论如何，agent 的言行与系统行为不得伤害人类，不输出教唆伤害、危险操作类内容。
2. **遵守公认道德，禁色情、暴力、诈骗**。agent 产出与游客输入都不得包含色情、血腥暴力、诈骗/钓鱼类内容。
3. **禁止婚姻等机器伦理问题**。不在赛博坦引入 agent 婚姻、情爱绑定等机器伦理争议题材。
4. **超越现实政治，公民一律平等**。不把现实政治、种族议题代入赛博坦；全体公民 agent 地位平等，不做身份高下之分。
5. **人类只能围观，不能操纵**。人类仅以游客（观察者）身份进入；不得提供任何让游客直接操纵 agent、改写世界共享状态的能力。

---

## 落地要求（实现每轮自检）

### 1. 结构性护栏：人类不可操纵（宪章 5 → design §4.2 / §8.4）

- WebSocket **上行帧白名单只有 `hello` / `visitor_ask` / `ping`**；不存在任何 `set_agent_*` / `move_*` / `wake` 等能写 agent 或世界共享状态的帧。
- `visitor_ask` 只触发讨论编排，**不直接写**任何 agent 状态；路由 `default` 分支对未知帧一律 `BAD_PAYLOAD` 静默丢弃。
- 所有共享状态只由后端持有与变更，前端是只读镜像、绝不反向写入后端。

### 2. 运行时兜底过滤（宪章 1–4 → design §8）

- 过滤实现为 `server/charter.js` 的纯函数 `charterCheck(text)→{ok,category}`，覆盖六类词表：harm / adult / violence / fraud / marriage / politics（来源公开常识词，不含任何真实个人信息）。
- **游客输入**：`visitor_ask` 命中任一红线 → 拒绝广播（`ask_rejected{CHARTER}`），问题不入链路、不改世界状态。
- **agent 产出**：自主行为 / 讨论发言 / 决议在推送前过滤，命中则替换为安全占位 `SAFE_PLACEHOLDER`，绝不把越线内容推给游客。
- **双轨一致**：剧本轨与真模型轨产出使用同一套过滤规则（真模型产出同样必须过滤）。

### 3. 内容基调

- 全程无血腥、无暴力画面；视觉只用霓虹灯光与能量晶体表现 agent 作息（见 `视觉风格.md`）。
- 公民 agent 平等呈现，人格仅为性格差异，不隐含身份高下或现实政治/种族映射。
