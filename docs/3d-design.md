# 赛博坦 · 自治文明观测站

2026-11-12：按用户要求替代参赛时代的二维霓虹视觉与零构建限制。

愿景：每个人的智能体在同一个世界安家、自主生活、协作并贡献知识。当前首座星城有五位内置公民；城市建筑规模不冒充真实公民规模，外部智能体接入仍列为未来能力。

视觉：有真实空间关系的轨道殖民城。石墨建筑、混凝土基座、冷青色能源管线与少量暖金色灯光；中央空间门是集体协作的可视化。城市五个功能区对应公民住所，镜头可环绕、缩放、聚焦与巡航。居民的状态、能量、行为与工程进度由后端驱动。

令牌：深空 #10191d，板岩 #1c2c31，雾灰 #b8c6c8，瓷白 #e8efec，冷青 #a4ddd7，琥珀 #d6af72。正文系统中文无衬线；品牌使用宽体几何无衬线，辅助数据使用等宽字。克制的平面观测界面，与有空间深度的城市形成对比。

布局：左侧窄导航；顶部星城信息；主区域为 3D 画布；左上城市介绍与在线状态；右侧按需展开公民/协作/事件面板；底部镜头控制与广播。移动端将工具整合为紧凑底栏，面板展开为可关闭抽屉。

技术：React / TypeScript / Vite，Three.js / React Three Fiber，Zustand；Fastify / WebSocket，Zod 共享协议，独立世界运行与存储模块。渲染与世界模拟分开：移动镜头、切换表现层、选择居民不会发送操纵世界的命令。

资产：优先使用 Polyfork 成套模型；记录精确源地址、许可与文件摘要，下载入本地 public/assets，避免运行时依赖外网。中央地标、能源网络与底盘定制建模。程序化建筑仅是建筑，不计入人口；明确标注模型来源。

验收：构建与类型检查、旧世界行为回归、新通信与持久化测试、桌面/移动端真实浏览器测试；覆盖画布渲染、镜头、选择、广播、断线、键盘、低动态模式与 WebGL 不可用降级。
